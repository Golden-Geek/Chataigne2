# Golden Audio UI

`golden_audio_ui` is the reusable Svelte 5 presentation package for the
backend-neutral device state generated by the Rust `golden_audio` crate. It
does not discover devices, negotiate streams, or persist application state.

## Registering a Golden node

Register an exact application node type during app setup:

```ts
import { registerGoldenAudioDeviceInspector } from 'golden_audio_ui';

registerGoldenAudioDeviceInspector('my_audio_node', (node) => createMyAudioBinding(node));
```

The exact node-type registration takes precedence over a generic
`user_item_kind` inspector. Call `unregisterGoldenAudioDeviceInspector` when a
registration is removed. Importing the package has no registration side
effect.

Applications can implement `AudioDeviceInspectorBinding` directly. Apps whose
audio node exposes ordinary Golden parameters can instead use
`createGoldenAudioDeviceParameterBinding`: provide the generated inspector
state, declared parameter paths or node IDs, and one function that translates
a `ParamValue` into the application's edit intent.

`AudioDeviceSelector` is also exported independently for composition in a
larger editor. `MockAudioDeviceInspectorAdapter` and `MockAudioDeviceConsumer`
provide a Chataigne-independent development harness.

## Generated contract

Run:

```sh
npm run codegen --workspace golden_audio_ui
npm run check:generated --workspace golden_audio_ui
```

The bindings are generated from Rust DTOs; TypeScript declarations must not be
edited by hand.
