MapGyver 2 now has beta packages for macOS, Linux, and Windows ARM64 alongside Windows x64.

- Apple Silicon and Intel Mac bundles include FFmpeg. Media Preview and Screen Warping use the portable GPU renderer. Native Rectangle and Fullscreen Screens can target selected displays.
- Ubuntu 24.04 x64 and Debian 13 ARM64 packages include the desktop workbench, local media playback, and X11 and Wayland display output. Debian 13 armhf packages are available for testing.
- The native Windows ARM64 installer includes ARM64 FFmpeg libraries and uses WebView2 for the workbench. Windows video decoding uses the selected GPU and falls back to software when it lacks hardware video support.

| Download | Target |
| --- | --- |
| `macos-arm64.zip` | Apple Silicon, macOS 13 or later |
| `macos-x86_64.zip` | Intel, macOS 13 or later |
| `ubuntu-24.04-amd64.deb` | Ubuntu 24.04 x64 |
| `debian-13-arm64.deb` | Debian 13 ARM64, including Raspberry Pi OS testing |
| `debian-13-armhf.deb` | Debian 13 32-bit ARM, including Raspberry Pi OS testing |
| `windows-x64-setup.exe` | Windows x64 |
| `windows-arm64-setup.exe` | Windows ARM64 |

The Windows installers are unsigned and install for the current user. The macOS bundles use ad hoc signatures. The armhf package passed clean install and headless project authoring under emulation. Physical display recovery and Raspberry Pi hardware checks remain open. Windows x64 NDI requires a separately installed runtime. Native Windows ARM64 ships without NDI.

The FFmpeg corresponding-source kit accompanies the installers. The tagged source includes [the Windows ARM64 build recipe](https://github.com/Golden-Geek/Chataigne2/blob/1.0.0b3/tools/mapgyver/ffmpeg/build-windows-arm64.sh) and [the macOS build recipe](https://github.com/Golden-Geek/Chataigne2/blob/1.0.0b3/tools/mapgyver/ffmpeg/bundle-macos.sh).
